# Deeper-Market
An application made for you to connect your preferred LLM in order to find relevant financial market data and information, then display it in an organized, easily understandable/readable, and user-friendly UI. The application is designed to give you the most recent and relevant market information based on your desired preferences and/or personal financial portfolio, using information and data gathered from well-known and lesser-known sources depending on your set preferences and LLM. Deeper-Market can help you build strong financial literacy, which can allow you to build long-term gains upwards of 25% to 50%.
